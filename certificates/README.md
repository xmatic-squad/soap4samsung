# Сертификаты не публикуются

Для установки Soap4Samsung каждый пользователь создаёт **свой** Samsung TV
certificate profile со своим author и distributor, содержащим DUID своего ТВ.
В открытом репозитории нет сертификатов, ключей или архивов подписи.

Пошаговое создание профиля, исправление default distributor и перенос на другой
компьютер: [docs/CERTIFICATES.md](../docs/CERTIFICATES.md).

Не добавляйте сюда `.p12`, `.pfx`, приватные ключи, `profiles.xml`, пароли
или резервные копии — **в том числе зашифрованные**. Локальный инструмент
`tools/certificates.py` по умолчанию создаёт архив в игнорируемой папке
`.local/certificates/`; храните дополнительную копию в личном резервном хранилище.

Для обновления своего установленного приложения сохраняйте тот же author.
Имя профиля `Soap4Samsung` общее только как пример; ключи у каждого пользователя свои.
