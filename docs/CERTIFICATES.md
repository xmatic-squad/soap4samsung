# Собственная подпись Samsung TV

Для самостоятельной установки каждый пользователь создаёт свой профиль Samsung TV:
**author certificate** и **distributor certificate** с DUID своего телевизора.
Сертификатов проекта и общих паролей для скачивания нет. Ни сертификаты,
ни их зашифрованные резервные копии не публикуются в GitHub.

Author определяет автора установленного пакета. Сохраните его для будущих обновлений.
Distributor разрешает установку на перечисленные устройства. Требования Samsung
и мастер создания описаны в
[Creating Certificates](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html).

## Подготовка

Установите Tizen Studio, Certificate Manager, TV Extensions и Samsung Certificate
Extension. Нужен собственный Samsung Developer account. Вход в Samsung выполняется
в окне авторизации; пароль не передавайте проекту и не записывайте в команды.
Для создания сертификатов после сентября 2025 года требуется Samsung Certificate
Extension не ниже 2.0.73 — см.
[установку SDK](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html).

Включите Developer Mode на ТВ, задайте Host PC IP вашего компьютера,
перезапустите ТВ и подключитесь через SDB, как описано в
[README](../README.md#самостоятельная-установка). Так мастер сможет предложить
ваш телевизор в списке DUID.

## Создать профиль в первый раз

1. В Tizen Studio откройте **Tools → Certificate Manager**.
2. Нажмите `+`, выберите **Samsung**, затем **TV**.
3. Назовите профиль `Soap4Samsung`. Имя профиля локальное; если выберете другое,
   подставляйте его в `--profile` при сборке.
4. Выберите **Create a new author certificate**. Заполните данные автора,
   задайте пароль сертификата и сохраните его в своём менеджере паролей.
5. Войдите в свой Samsung-аккаунт в открывшемся окне. Сохраните резервную копию
   сертификата в личной папке вне репозитория.
6. Выберите **Create a new distributor certificate**, уровень **Public**,
   задайте и сохраните его пароль.
7. Добавьте **DUID своего ТВ** кнопкой `+` рядом с подключённым устройством.
   Проверьте, что устройство действительно отмечено в списке. Если подключить
   не удаётся, DUID можно взять на самом ТВ в разделе поддержки/информации
   об устройстве и ввести вручную; расположение пункта зависит от прошивки.
8. Завершите мастер кнопкой **Finish** и оставьте профиль активным.

Public здесь — уровень сертификата. Для личной установки не требуется
публиковать приложение в Samsung Store или получать статус издателя магазина.
Не используйте чужой DUID: нужен идентификатор того ТВ, на который ставите пакет.

## Проверить и подписать

В Bash укажите фактический путь к установленному SDK:

```sh
soap_sdk="$HOME/tizen-studio"
soap_tizen="$soap_sdk/tools/ide/bin/tizen"
"$soap_tizen" security-profiles list
python3 tools/package.py --profile Soap4Samsung --tizen "$soap_tizen"
```

Профиль должен быть в списке; итоговый пакет — `.local/Soap4Samsung.wgt`.
Пароли сертификатов при этом в аргументы команды не добавляются: ими управляет SDK.
Полная установка описана в [README](../README.md#5-подписать-установить-и-запустить).

Если мастер выбрал **SDK default distributor certificate** или в профиле виден
`tizen-distributor-signer`, вернитесь к созданию **Samsung distributor** и добавьте
DUID своего ТВ. Существующий author сохраните. Если мастер уже закрыт, откройте
редактирование/повторное создание профиля, выберите существующий author и создайте
новый distributor с нужным устройством. В результате обе части должны относиться
к Samsung TV; обычный distributor из SDK для нашей установки на Samsung не подходит.

При истечении срока distributor или добавлении другого телевизора создайте
обновлённый distributor с нужным DUID, сохраняя прежний author. Сроки проверяйте
в Certificate Manager — у каждого профиля они свои.

## Личная резервная копия

Храните author, distributor и их пароли так, чтобы пережить переустановку компьютера.
Простого клонирования этого репозитория для восстановления вашей подписи недостаточно.
Архивы подписи, включая зашифрованные, должны оставаться в вашем личном хранилище
**вне Git, issues и вложений к релизам**.

В проекте есть необязательный Linux-инструмент резервного копирования.
Для него нужны Python 3.9+, GnuPG; для окна пароля — также Zenity.
Укажите путь к `profiles.xml` именно **каталога данных вашего SDK**, выбранного
при установке Tizen Studio. Ниже показан пример стандартной папки в домашнем каталоге:

```sh
python3 tools/certificates.py backup \
  --profile Soap4Samsung \
  --profiles "$HOME/tizen-studio-data/profile/profiles.xml" \
  --password-gui
```

По умолчанию результат сохраняется в игнорируемую папку
`.local/certificates/Soap4Samsung.tar.gpg`. Перенесите копию в личное резервное
хранилище вне рабочей папки. Можно сразу задать собственный путь через `--archive`:

```sh
python3 tools/certificates.py backup \
  --profile Soap4Samsung \
  --profiles "$HOME/tizen-studio-data/profile/profiles.xml" \
  --archive "$HOME/PrivateBackups/Soap4Samsung.tar.gpg" \
  --password-gui
```

Пароль архива вводится только в локальном окне; без `--password-gui` он
запрашивается в терминале без отображения. Инструмент шифрует архив GPG/AES-256
и проверяет расшифровку перед сохранением. В архив входят выбранный профиль SDK,
активные author/distributor и дополнительные файлы папки сертификатов профиля.

**Пароль архива и исходные пароли P12 — разные вещи.** Сохраните все нужные
пароли в своём менеджере паролей. Архив содержит приватные ключи и сведения
профиля: шифрование не делает его подходящим для открытой публикации.

## Перенос на другой компьютер

1. Установите SDK и расширения на новом компьютере. Подключите свой ТВ.
2. Восстановите свой архив, используя его локальный путь:

   ```sh
   python3 tools/certificates.py restore \
     --archive "$HOME/PrivateBackups/Soap4Samsung.tar.gpg" \
     --output .local/certificates-restored \
     --password-gui
   ```

3. В Certificate Manager создайте профиль **Samsung → TV → Soap4Samsung**.
4. Выберите **Select an existing author certificate** и восстановленный
   `.local/certificates-restored/active-profile/author.p12`; введите его исходный пароль.
5. Импортируйте `active-profile/distributor.p12` с его паролем. Если distributor
   истёк, создайте новый для своего ТВ, оставив восстановленный author.
6. Сделайте профиль активным, подпишите и установите пакет поверх прежнего приложения.

Восстановление проверяет контрольные суммы; существующий каталог назначения
не перезаписывается. Копия `profile/profiles.xml` внутри архива относится к старой
установке SDK. Не заменяйте ею профиль нового SDK вслепую: пути и хранилище паролей
могли измениться, поэтому используйте импорт через Certificate Manager.

При обычных обновлениях сохраняются **прежний author**, app ID
`Soap4TV001.Soap4Samsung` и package ID `Soap4TV001`. Потеря author может помешать
обновлению поверх уже установленного пакета; создание нового сертификата
с таким же именем не восстанавливает старый ключ.
