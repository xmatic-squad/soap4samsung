# Работа над Soap4Samsung

Soap4Samsung — открытый минимальный клиент Soap4me для Samsung Tizen TV.
Проверенная цель: Samsung QE55Q70TAUXRU, Tizen 5.5, Chromium 69.
Первая установка: [README.md](README.md).
Цикл разработки и обновления: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
Собственные сертификаты: [docs/CERTIFICATES.md](docs/CERTIFICATES.md).
Наблюдаемый API: [docs/API.md](docs/API.md).

## Решения по приложению

- Основные разделы: «Избранное», «Сериалы», «Фильмы», «Настройки»; внутри —
  сезоны и серии, карточка фильма. Избранное сериалов один раз импортируется
  из `/soap/my/`, затем меняется только локально; у фильмов отдельный фильтр
  «Избранные». Сохранять минимализм, быстрое управление пультом и отсутствие
  внешних JS-зависимостей.
- Поиск открывает собственную клавиатуру RU/EN только по OK/клику, не при фокусе.
  Открывающее нажатие OK не вводит первую букву. «Найти» применяет запрос,
  Back отменяет черновик. Поиск учитывает все слова и варианты названия, ё/е.
- Выбирать русскую озвучку (`translate=4`) и максимальное доступное качество:
  4K → FullHD → 720p → SD. Этот порядок действует для сериалов и фильмов.
  Оригинальные дорожки, субтитры и их настройки пока не нужны.
- Для фильмов исходный HLS master использовать только для выбора AVC до 4K
  и русской аудиогруппы. По их child URI запрашивать у CDN фильтрованный master
  с одним выбранным видео, русским звуком и без субтитров; повторно проверять
  ответ. Его битрейт фиксировать через `ADAPTIVE_INFO` до `prepareAsync`.
  Исходный master с субтитрами вызывал закрытие процесса; fallback к нему
  не добавлять. Директория child URI может отличаться от исходного master.
  Не заменять поток локальным файлом или прямым video-плейлистом без аудио.
- Индикатор качества брать из фактического разрешения декодера, кэшировать
  успешное чтение для текущего запуска. Подпись плавно скрывается с панелью
  управления за 220 мс, на паузе панель остаётся видимой.
- Стрелки перемотки: одиночное нажатие — 10 секунд, удержание — шаги
  10/30/60/120/300 секунд после 0/2/5/9/15 секунд, не чаще шага в 500 мс.
  Отпускание и смена кнопки сбрасывают ускорение; отдельные FF/Rewind начинают
  с 30 секунд. Сохранять объединение повторов и очередь незавершённого seek.
- Локальная отметка просмотра важнее `watched` сервиса, включая явное снятие.
  Без неё использовать `watched`; обычный прогресс не перекрывает сервер,
  повторный просмотр и перемотка назад отметку не снимают.
  «Просмотрено» — естественный конец либо позиция ≥ 90 % при минимум 30 секундах
  воспроизведения с последней успешной перемотки; зафиксировать до автоперехода.
  Отметки серии, фильма, сезона и сериала, их снятие и прогресс — только локальные,
  без записи на Soap4me. Массовая отметка затрагивает только загруженные серии.
- Продолжение серии и фильма: при локальном статусе не `watched` и позиции
  > 60 секунд — на 5 секунд раньше; иная локальная запись — старт с 0.
  Без локальной записи использовать `start_from` сервиса (у фильма — 0).
  «Сначала» всегда запускает с 0; серверный `watched` сам по себе продолжению
  не мешает. Сохранять подтверждённую позицию раз в 15 секунд по событиям времени,
  при паузе, Back, Home, `pagehide` и конце, до обнуления плеера.
- В «Избранном» и «Фильмах» без поискового запроса на первой странице есть ряд
  «Продолжить» до 6 карточек. Долгое OK (600 мс) открывает меню избранного
  на карточке, «Смотреть сначала» и отметку на серии; короткое OK срабатывает
  при отпускании. Back из сетки переводит фокус на разделы; следующий Back
  показывает подсказку выхода, ещё один в течение 2 секунд закрывает приложение.
- Состояние просмотра и избранное хранятся на ТВ в `localStorage`:
  `soap4samsung.local.meta`, `soap4samsung.local.favorites`,
  `soap4samsung.local.show.<sid>`, `soap4samsung.local.movie.<id>`.
  Выход из аккаунта их сохраняет. Сброс в настройках удаляет только эти данные
  и разрешает повторный импорт; вход, сортировки и фильтр фильмов сохраняются.
- После естественного окончания серии автоматически открывать следующую
  серию того же сезона. После последней возвращаться к списку серий.
  Back, ошибка плеера и уход через Home не запускают следующую серию.
- Для фильмов автопереход не нужен: после конца фильма возвращаться к его
  карточке. Карточки каталога квадратные, изображение целиком, название
  поверх затемнения; использовать обложки сезонов, когда их возвращает API.
- Порядок «Избранного» по умолчанию: сначала сериалы с непросмотренными сериями.
  Фильмы по умолчанию сортируются по году по убыванию. Меню каждого раздела
  предлагает название, год, IMDb, Кинопоиск и Soap4me; «Избранное» — также непросмотренные.
  Выбор сохраняется локально отдельно для разделов. Смена порядка использует
  загруженный каталог без GET. Рейтинги брать только из `imdb_rating`,
  `kinopoisk_rating`, `soap_rating`: числа или числовые строки в диапазоне (0, 10].
  На карточках подписи IMDb/КП/Soap; отсутствующие оценки не показывать и сортировать последними.
  Сетка каталога на ТВ: 7×3, до 21 карточки; при ряде «Продолжить» на первой
  странице — 7×2 (14), далее — 21. Серии: 4×4, до 16 на странице.
  Стрелки вниз/вверх на границе сетки перелистывают страницы с сохранением колонки.
- Основной API: `https://api.soap4youand.me/v2`. На проверенном ТВ исходный
  `api.soap4.me` зависал при загрузке каталога; зеркало проверено на устройстве.
- Установленное приложение работает напрямую с сервисом и AVPlay. Компьютер
  нужен для разработки и установки, а не для обычного просмотра.
- Пользователь входит в Soap4me на телевизоре. Сборка не должна требовать
  аккаунта сервиса или включать его учётные данные.

## Совместимость и проверки

- Целевой движок — Chromium 69 / Tizen 5.5. Сохранять совместимый JavaScript
  в существующем стиле: обычные функции и `var`; Promise допустимы.
  Не добавлять optional chaining, nullish coalescing и современные CSS/API
  без проверки поддержки на ТВ.
- API находится в `app/api.js`, интерфейс и фокус — в `app/main.js`,
  AVPlay и браузерный fallback — в `app/player.js`, клавиатура — в `app/keyboard.js`,
  рейтинги, сравнение названий и сортировка — в `app/catalog.js`,
  локальные отметки, прогресс и избранное — в `app/store.js`.
- После изменений выполнять `npm test` и `npm run build`. Тесты должны
  проверять поведение, ошибки и гонки; для простой правки текста отдельный
  тест не нужен. Изменения плеера проверять и на реальном устройстве.
  Если ТВ недоступен, явно указать границу выполненных проверок.
- Сборщик использует явный список публичных ресурсов `PUBLIC_FILES`
  в `tools/package.py`. При добавлении ресурса обновлять этот список;
  не заменять его рекурсивным копированием всех файлов из `app/`.
- Пока `AVPlay.seekTo` не вызвал success/error callback, другие вызовы
  AVPlay откладываются. Сохранять очередь паузы/остановки/нового запуска
  и защиту от callbacks предыдущей серии.
- На проверенном ТВ `Page.captureScreenshot` через CDP зависал. Для проверки
  интерфейса использовать DOM и состояние плеера; изображение и звук
  проверять на экране телевизора.

## Обновление и подпись

- Каждый пользователь создаёт свои Samsung author/distributor с DUID своего ТВ.
  `Soap4Samsung` — рекомендуемое имя локального профиля.
  App ID: `Soap4TV001.Soap4Samsung`; package ID: `Soap4TV001`.
  Не менять эти идентификаторы и авторский сертификат при обычном обновлении.
- Обновлять установкой нового `.wgt` поверх приложения, сохраняя свой author.
  Сначала завершить приложение через `was_kill`; не использовать uninstall
  в обычном цикле, чтобы сохранить вход и данные приложения.
- Если пользователь уже поручил обновление своего ТВ или публикацию изменений
  в Git, доводить работу до проверки результата; повторное разрешение
  на те же согласованные действия не требуется.
- Пути SDK, IP компьютера/ТВ и имя профиля задаются локально. В документации
  использовать явно обозначенные примеры, не реальные данные участника.
  `.env.example` содержит только пример окружения, без аккаунта сервиса.

## Секреты, Git и публикация

- Публичный проект: `https://github.com/xmatic-squad/soap4samsung`.
  Проверять текущую ветку и diff перед коммитом, не включать чужие изменения.
  Внешние изменения принимаются через PR с одобрением CODEOWNERS.
- В существующей рабочей копии может быть приватная история. Перед публикацией
  проверить `git config --get soap4samsung.publicBranch`. Если значение задано,
  выполнять локальную инструкцию `.local/PUBLISHING.md` и отправлять только
  указанную публичную ветку. Не отправлять все ветки, теги или `--mirror`.
  В обычном клоне публичного репозитория такой настройки нет.
- Пароли, токены, cookie-значения, полные ссылки на видео, данные профиля подписи
  и реальные DUID не помещать в исходники, коммиты, issues, PR или журналы.
  Не выводить полный localStorage, API-ответ авторизации или сетевые заголовки.
- Сертификаты, приватные ключи, P12, `profiles.xml` и любые резервные копии
  подписи, включая зашифрованные архивы, в публичный Git не добавлять.
  Личный архив создаётся через `tools/certificates.py` в игнорируемую `.local/`
  или личное хранилище вне репозитория. Пароль вводится локально; инструкция
  находится в `docs/CERTIFICATES.md`.
- `.local/`, `.env`, SDK/workspace, `.buildResult/`, `.wgt`,
  `app/config.local.js`, сессии и распакованные архивы остаются локальными.
  Сборщик создаёт `config.local.js` только с публичным номером версии.
- Тестовые ответы должны быть синтетическими. Не переносить реальные сетевые
  дампы в fixtures, не использовать приватную сессию в CI и не запрашивать
  пароли участников для воспроизведения их issue.
